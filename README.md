# D-Day 4.29 투자 공부 플랜

2026년 9월 21일부터 2027년 4월 29일까지, 221일 동안 미국주식과 암호화폐 투자를 공부하는 하루 단위 계획표입니다. 가치투자·장기투자와 스윙 트레이딩을 함께 다룹니다.

빌드 과정이나 의존성 없이 `index.html` 파일 하나로 동작합니다.

## 기능

- 오늘 할 일과 목표 시간(분)을 맨 위에 표시
- 221일을 한 칸씩 보여 주는 진행 막대 (완료, 지난 날, 오늘 구분)
- 32주 과정을 주차별로 접고 펼치기, 날짜별 체크박스
- 완료 기록을 클립보드로 내보내기, 초기화
- 라이트/다크 모드, 모바일 화면 대응

체크 기록은 브라우저 `localStorage`에 저장되므로 기기마다 따로 관리됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

GitHub Pages로 배포하려면 리포의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 지정하세요.

## 수정하기

모든 일정 데이터는 `index.html` 안의 `<script>`에 있습니다.

- `W`: 주차별 목록. `s`는 주 시작일(월요일), `t`는 주 제목, `m`은 주 유형(`sem` 학기, `vac` 방학, `exam` 시험, `hol` 연휴), `d`는 월요일부터 일요일까지 하루 과제 7개입니다. `null`을 넣으면 요일별 기본 과제(화요일·토요일 시장 체크)가 들어갑니다.
- `SEM`, `VAC`, `EXAM`: 유형별 요일당 목표 시간(분)
- `END`: 마지막 날
