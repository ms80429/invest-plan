# D-Day 4.29 투자 준비

2027년 4월 29일, 증권 계좌와 거래소를 열고 규칙대로 첫 매수를 하는 날까지 필요한 것만 거꾸로 고른 카드 38장입니다. 미국주식(장기·가치, 스윙)과 암호화폐를 다룹니다.

빌드 과정이나 의존성 없이 `index.html` 파일 하나로 동작합니다.

## 왜 바꿨나

이전 버전은 221일을 하루 한 칸씩 체크하는 계획표에 책 9권이 들어 있었습니다. 바쁜 하루가 밀리면 빈 칸이 쌓였고, 그 칸들이 공부 대신 자책을 만들었습니다. 6일 만에 멈췄습니다.

- **하루 단위 칸이 없습니다.** 맨 위에는 D-day와 남은 카드 수, "며칠에 한 장이면 충분한지"만 보입니다. 쉰 날은 기록되지 않습니다.
- **책이 뼈대가 아닙니다.** 4월 29일에 실제로 필요한 것(투자 가능 금액, 비용과 세금, 손실과 사이징, 기업 숫자 읽기, 손절 규칙, 코인 보안, 규칙서)에서 거꾸로 골랐습니다.
- **"오늘은 말고"는 실패가 아닙니다.** 그 카드가 맨 뒤로 가고, 숫자는 그대로입니다.

## 카드 구조

1. **먼저 답을 정해 보세요** — 예: "반토막 난 주식이 원금으로 돌아오려면 몇 % 올라야 할까요?"
2. **직접 확인하기** — 계산식, TradingView, 재무제표, 공시 등 답이 눈에 보이는 곳
3. **왜 그런지** — 확인한 다음에 읽는 원리

받아 적기가 되지 않게 이 순서로 둡니다. 카드에 적힌 계산 결과는 모두 실제로 계산해 확인한 값입니다. 과거 시장 수치(-57%, -78%, -77%)는 근삿값이며, 카드가 시키는 대로 차트에서 직접 재 보는 것이 정답입니다.

| 단계 | 카드 | 내용 |
|---|---|---|
| 출발점 | 1–5 | 복리, 시간, 투자 가능 금액, 손실의 비대칭, 투자 이유 세 줄 |
| 상품과 비용 | 6–11 | ETF, 시가총액 가중, 보수, 환율, 국내/미국 상장 세금, 매매 비용 |

| 차트와 규칙 | 25–30 | 지지·저항, 이동평균, 거래량, 모의매매와 복기 |

## 실행

`index.html`을 브라우저로 열면 됩니다. 진행 상황은 이 브라우저의 `localStorage`에 저장되므로 기기마다 따로 관리됩니다. 이전 버전의 체크 기록(`invplan-v1`)은 지우지 않았습니다.

`index.html?test`를 서버로 열면(예: `python -m http.server`) 큐 동작과 카드 데이터 점검이 콘솔에서 돌아갑니다.

## 수정하기

카드는 `index.html` 안 `<script>`의 `C` 배열입니다. `p` 단계, `t` 제목, `q` 질문, `c` 확인 방법, `s` 어디서, `w` 확인 결과 힌트, `m` 원리. `END`는 D-day입니다.
